# PoopFare

Satirical poop allocation game — Next.js app lives in `web/`.

## Quick start

```bash
cd web
npm install
npm run dev
```

## Production

```bash
cd web
npm run build
npx vercel login    # once
npx vercel --prod
```

See [web/DEPLOY.md](web/DEPLOY.md) for env vars, daily fetch automation, and post-deploy checklist.
